Case studies

Case 01 Technology & mobility

110K+ endpoint on-premises to SaaS migration

Context

One of India's largest technology and mobility enterprises, running a 110,000+ endpoint estate on an on-premises ePolicy Orchestrator platform.

Delivery

Led the migration to ePO SaaS end to end, migrating and tuning DLP policies for parity, and supported security governance through GDPR and compliance documentation reviews, data-flow assessment and cloud-migration readiness.

Outcome

Policy parity maintained across the estate with post-migration stability on the SaaS platform.

Case 02 Large enterprise

Security platform recovery at 120K endpoints

Context

A 120,000-endpoint security management platform with degraded performance, a 1.3 TB database and poor console responsiveness.

Delivery

Health assessment and configuration gap analysis, platform and database remediation, and policy optimisation with post-deployment stabilisation.

Outcome

Database footprint reduced from 1.3 TB to approximately 600 GB, with restored console responsiveness and operational reliability.

Case 03 Automation

API automation beyond out-of-the-box capability

Context

An ePO SaaS estate needing SIEM event forwarding and bulk lifecycle operations the console does not provide natively.

Delivery

Built and operationalised custom Python API automation for Trellix ePO SaaS, forwarding security events to Microsoft Sentinel and handling bulk system deletion and System Tree moves.

Outcome

Repeatable automation in production, extending platform capability and removing manual estate housekeeping.
